La storia

Perché esiste FantaGiustiziere?

Tutto è cominciato con una discussione che si ripete ogni fine stagione in qualsiasi lega fantacalcistica: "Hai vinto perché sei il più forte, o perché il calendario ti ha favorito?" La risposta intuitiva spesso non regge all'analisi — c'è chi finisce primo con punteggi mediocri e chi produce fantasticamente ma chiude quinto.

FantaGiustiziere nasce per dare una risposta numerica a quella domanda. Invece di affidarsi all'impressione, prende i punteggi reali della stagione e ricalcola sistematicamente la classifica per ogni calendario alternativo possibile — fino a centinaia di migliaia di scenari diversi.

Il risultato non è una previsione né un giudizio: è uno specchio statistico che mostra, nero su bianco, quanto il sorteggio abbia pesato sul risultato finale.

Come funziona — in breve

Quattro passi per scoprire la verità sul tuo calendario

1
Carica il file Excel della tua lega — quello esportato dalla piattaforma con i punteggi di ogni giornata per ogni giocatore.
2
Configura i parametri: vantaggio casalingo, soglia e intervallo per il calcolo dei gol. L'app mostra subito la classifica attuale.
3
Scegli la profondità di analisi: da mille permutazioni rapide fino al calcolo completo di tutti i calendari possibili.
4
Leggi i risultati: quante volte ogni giocatore avrebbe vinto con un calendario diverso, con uno slider per simulare diversi valori di vantaggio casalingo.
Vuoi capire la matematica dietro? La pagina 📐 Come funziona spiega l'algoritmo di Heap, l'algoritmo di Berger e la combinatoria del fattoriale.
Stack tecnologico

Costruito con strumenti solidi e gratuiti

FantaGiustiziere è un progetto personale sviluppato interamente con tecnologie open source. Il backend gira su Java 21 con Spring Boot; il frontend è HTML, CSS e JavaScript vanilla — nessun framework, nessuna dipendenza inutile.

☕ Java 21 Backend / algoritmi
🌱 Spring Boot 3 REST API / server
📊 Apache POI Parsing Excel
🌐 Vanilla JS Frontend / UI
🎨 CSS3 Stile / animazioni
🚀 Async API Calcolo non bloccante

Il calcolo delle permutazioni usa l'algoritmo di Heap per generare tutti gli ordinamenti senza ripetizioni, con supporto multi-thread per sfruttare i core disponibili. I job di calcolo girano in modo asincrono: il browser aggiorna il contatore in tempo reale tramite polling, senza bloccare l'interfaccia.
